# mkon-formatter

Форматирование файлов `.mkon` в Visual Studio Code.

![Пример](example.gif)

## Что такое mkon?

[mkon](https://github.com/Sam-Strand/mkon-js) — это удобный для чтения формат JSON, допускающий более свободный синтаксис.

После установки расширения файлы `.mkon` можно форматировать стандартной командой VS Code **Форматировать документ** (`Shift+Alt+F`).

## Настройка

Расширение поддерживает настройку параметров форматирования. Доступные параметры соответствуют API пакета [mkon](https://github.com/Sam-Strand/mkon-js).

## Форматировщик по умолчанию

Если у вас установлено несколько расширений, поддерживающих форматирование mkon, можно явно назначить `mkon-vsc` форматировщиком по умолчанию.

Откройте настройки VS Code в формате JSON и добавьте:

```json
{
  "[mkon]": {
    "editor.defaultFormatter": "Sam-Strand.mkon-vsc"
  }
}
```

Расширение использует пакет mkon.
